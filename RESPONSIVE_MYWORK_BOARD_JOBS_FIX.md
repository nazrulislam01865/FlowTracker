# Responsive My Work / Board / Jobs update

- My Work and Task Board keep the existing Job-grouped logic on desktop, but switch to a vertical Job/status layout on small screens instead of forcing horizontal board scrolling.
- Empty task status lanes are hidden on small screens; populated lanes get a clear status header.
- Job Board phases become full-width collapsible sections on small screens.
- Board/My Work filters and quick filters use responsive grids and never require horizontal scrolling.
- Jobs filters, quick filters, bulk controls and pagination are responsive.
- The Jobs table becomes mobile Job cards while retaining all dynamic Livewire actions, owner/date editing, permissions and selection.
- Desktop/tablet layouts and existing drag/drop/business logic are unchanged.
